# Deep Learning Demos

Interactive visualizations for understanding deep learning algorithms and papers.

## Demos

### [Rosenblatt's Perceptron Algorithm](./perceptron/)

[▶ Launch Interactive Demo](https://cadyehoffmann.github.io/deep-learning-demos/perceptron/)

An interactive visualization of the perceptron learning algorithm. Watch the model identify misclassified points, apply the perceptron update rule, and see how each update changes both the decision boundary in data space and the weight vector in weight space.

**Concepts:** linear classification, decision boundaries, weight vectors, perceptron updates, data space, and weight space.

### [Backpropagation Explorer](./backprop/)

[▶ Launch Interactive Demo](https://cadyehoffmann.github.io/deep-learning-demos/backprop/)

An interactive visualization of forward propagation, backpropagation, and gradient descent in a small neural network. Step through the forward calculations, trace gradients backward using the chain rule, interpret derivatives using the "penny" question, and watch the network learn over repeated training iterations.

**Concepts:** forward propagation, sigmoid activations, loss, backpropagation, chain rule, gradients, gradient descent, weight updates, and neural network training.
