# Deep Learning Demos

Interactive visualizations for understanding deep learning algorithms and papers.

## Demos

### [Rosenblatt's Perceptron Algorithm](./perceptron/)

[▶ Launch Interactive Demo](https://cadyehoffmann.github.io/deep-learning-demos/perceptron/)

An interactive visualization of the perceptron learning algorithm. Watch the model identify misclassified points, apply the perceptron update rule, and see how each update changes both the decision boundary in data space and the weight vector in weight space.

**Concepts:** linear classification, decision boundaries, weight vectors, perceptron updates, data space, and weight space.
